# super-hallucinations
I conducted an experimental comparison of four RAG configurations to investigate whether retrieval actually reduces hallucination. I evaluated answer correctness, groundedness, citation accuracy, retrieval quality, and abstention behavior, including adversarial cases.
And we can build this together

I suggest we do it in four stages:

Stage 1: Design the experiment and create the 50–100 question dataset.
Stage 2: Build the basic RAG application.
Stage 3: Run the four experiments and generate the actual results/charts.
Stage 4: Write the technical paper around our actual findings, including the failures.

That last point is important: we shouldn't decide the conclusion beforehand. If RAG performs poorly in one experiment, that's potentially the most interesting finding.
